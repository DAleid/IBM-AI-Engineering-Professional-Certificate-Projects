## Projects

### Australian Weather Prediction
**Path:** [`AUSWeather/`](AUSWeather/)

Predicts whether it will rain the next day in Australia using supervised classification models trained on historical weather data from the Bureau of Meteorology.

| Aspect | Details |
|--------|---------|
| Dataset | Australian weather observations |
| Task | Binary classification — Rain tomorrow: Yes / No |
| Models | Logistic Regression, Decision Tree, KNN, SVM |
| Framework | scikit-learn |
| Notebook | [FinalProject_AUSWeather.ipynb](AUSWeather/FinalProject_AUSWeather.ipynb) |
